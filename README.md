# VoxMorph

Процедурный аудиореактивный VTuber для Linux. Персонажи создаются в реальном времени из математических форм — без PNG-слоёв, рисования и веб-камеры.

## Статус

Ранний прототип. Сейчас реализуется браузерное ядро; упаковка в Tauri и интеграция с OBS — следующие этапы.

## Запуск

Требуется Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес Vite в браузере, разрешите доступ к микрофону и нажмите «Запустить».

## Текущие возможности

- Процедурное симметричное существо на WebGL 2.
- Анализ микрофона: громкость, басы, середина и высокие частоты.
- Реакция формы, глаз и внутренних деталей на голос.
- Генерация нового облика и настройка палитры.
- Прозрачный фон сцены для будущего захвата в OBS.

## План

1. Рабочий аудиореактивный прототип.
2. Настройки поведения и сохранение пресетов.
3. Прозрачное отдельное окно и упаковка в Tauri 2.
4. Оптимизация для старых GPU и документация по OBS.

## Стек

TypeScript, Vite, WebGL 2 / GLSL, Web Audio API. Tauri 2 добавим после проверки графического ядра.
