# VoxMorph

Процедурный аудиореактивный аватар для Linux и OBS. Приложение запускается отдельным desktop-окном: Electron получает микрофон, Web Audio API анализирует сигнал, WebGL2 рисует существо.

## Требования

- Ubuntu/Linux x64
- Node.js 20+ и npm
- Поддержка WebGL 2 графическим драйвером

## Запуск для проверки без OBS

```bash
git clone https://github.com/spbRusty/VoxMorph.git
cd VoxMorph
npm install
npm run desktop:dev
```

Откроется обычное окно VoxMorph. Нажми «Запустить микрофон» и выбери устройство ввода. В браузере запускать не требуется.

## Сборка приложения

```bash
npm run desktop:build
```

AppImage появится в каталоге `release/`. Запуск:

```bash
chmod +x release/VoxMorph-*.AppImage
./release/VoxMorph-*.AppImage
```

## Использование в OBS

1. Запусти VoxMorph и подключи микрофон.
2. Нажми «Режим OBS». Останется существо на прозрачном фоне.
3. В OBS добавь источник захвата окна и выбери VoxMorph.
4. Для выхода из прозрачного режима нажми `Ctrl+Shift+O`.

В OBS-режиме окно фиксируется в размере 720×720, становится прозрачным, находится поверх остальных окон и пропускает клики. Горячая клавиша возвращает обычный интерфейс.

**Примечание:** прозрачность захвата зависит от композитора Linux и способа захвата в OBS. Её нужно проверить на целевой системе; если OBS покажет чёрный фон, потребуется альтернативный способ передачи изображения.

## Запуск браузерной версии для разработки

```bash
npm run dev
```

Для доступа к микрофону в браузере требуется `http://localhost` или HTTPS.
